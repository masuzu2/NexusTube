# NexusTube — คู่มือการใช้งาน (v3.9.0)

## 1. ติดตั้ง

### แบบติดตั้ง (แนะนำ)
1. ดาวน์โหลด [NexusTube-Setup-3.9.0.exe](https://github.com/masuzu2/NexusTube/releases/latest/download/NexusTube-Setup-3.9.0.exe)
2. เปิดไฟล์ → เลือกภาษา (ไทย/อังกฤษ) → อ่าน license → เลือกโฟลเดอร์ที่ต้องการ → ติดตั้ง
3. แอปจะเปิดให้อัตโนมัติ พร้อมปุ่มบน Desktop และ Start Menu

### แบบ Portable
ดาวน์โหลด [NexusTube-3.9.0-Portable.exe](https://github.com/masuzu2/NexusTube/releases/latest/download/NexusTube-3.9.0-Portable.exe) แล้วดับเบิลคลิกได้เลย ไม่ต้องติดตั้ง

> เครื่องต้องเป็น Windows 10/11 · ไม่ต้องติดตั้ง yt-dlp หรือ ffmpeg เอง แอปจัดการให้เอง

## 2. โหลดเพลง

### จากในแอป
1. ไปที่หน้า **ดาวน์โหลด** (sidebar ซ้าย)
2. ค้นหาชื่อเพลง หรือ **วางลิงก์** จาก YouTube / Spotify / Apple Music / SoundCloud (Playlist ก็ได้ — จะให้เลือกแทร็กแบบ batch)
3. เลือกรูปแบบไฟล์: MP3 320k / M4A / FLAC / MP4 → กดโหลด
4. เฝ้าดูคิวได้เรียลไทม์ (%, ความเร็ว, เวลาที่เหลือ) และยกเลิก/ลองใหม่ได้รายงาน
5. เพลงที่เสร็จแล้วฝัง cover art + metadata + เนื้อเพลงให้อัตโนมัติ

**ที่เก็บไฟล์**: `Downloads\NexusTube` (เปลี่ยนได้ในหน้าตั้งค่า)

### จากเว็บโหลดเพลง (Local-first)
1. เปิดแอป NexusTube ทิ้งไว้
2. เปิดเบราว์เซอร์ไปที่ `http://127.0.0.1:8787`
3. ค้นหา / วางลิงก์ → ใส่คิว → ไฟล์จะลงที่โฟลเดอร์เดียวกัน ปุ่ม "เปิดไฟล์" จะพาไปยังไฟล์ทันที

หรือจะรันเว็บโหลดแยกโดยไม่เปิดหน้าต่างแอป: ใช้ปุ่ม `START_WEB.bat` ที่มากับตัวติดตั้ง

เว็บนี้รันบนเครื่องคุณเท่านั้น (ไม่มีเซิร์ฟเวอร์ส่วนกลาง) — หน้า [masuzu2.github.io/NexusTube](https://masuzu2.github.io/NexusTube/) จะตรวจหาให้อัตโนมัติว่าเว็บในเครื่องเปิดอยู่ไหม

## 3. เล่นเพลง

- **คลังเพลง**: เพิ่มโฟลเดอร์เพลงในเครื่อง แอปสแกนให้อัตโนมัติ ค้นหาได้ทันที
- **ซับเนื้อเพลง Karaoke**: เปิดหน้า Lyrics ระหว่างเล่น — เนื้อร้องเลื่อนตามจังหวะ คลิกท่อนไหนก็ข้ามไปท่อนนั้นได้ กดปุ่มบันทึกเพื่อเก็บไฟล์ `.lrc` คู่กับเพลง
- **Equalizer**: 5 band ปรับได้ ±15dB มี preset สำเร็จรูป 8 แบบ
- **Sleep Timer**: ตั้งเวลาหยุดเพลงอัตโนมัติ
- **ควบคุมจากที่ไหนก็ได้**: System tray + hotkeys ทั่วระบบ และโชว์สถานะบน Discord (Rich Presence)

## 4. อัปเดตแอป

แอปตรวจเวอร์ชันใหม่จาก GitHub Releases อัตโนมัติ ถ้ามีเวอร์ชันใหม่จะแจ้งในแอปแล้วอัปเดตตัวเอง — ถ้าอัปค้างกลางทาง ระบบจะคืนไฟล์เดิมให้เองตอนเปิดครั้งถัดไป (ไม่มีทางพังจนเปิดไม่ได้)

อัปเองก็ได้: ดาวน์โหลดตัวติดตั้งใหม่จาก [Releases](https://github.com/masuzu2/NexusTube/releases) แล้วติดตั้งทับ

## 5. แก้ปัญหาที่พบบ่อย

| อาการ | วิธีแก้ |
|-------|--------|
| เว็บ `127.0.0.1:8787` เปิดไม่ได้ | ต้องเปิดแอป NexusTube ไว้ก่อน (หรือรัน `START_WEB.bat`) |
| ค้นหาแล้วไม่เจอ / โหลดไม่ได้ | รอสักครู่ — รอบแรกแอปกำลังดาวน์โหลด yt-dlp/ffmpeg อยู่ |
| เครื่องมือเตือน SmartScreen ตอนติดตั้ง | กด "More info" → "Run anyway" (ไฟล์ยังไม่ได้ sign) |
| ลืมว่าไฟล์เพลงอยู่ไหน | ดูที่ `Downloads\NexusTube` หรือกด "เปิดโฟลเดอร์" ในหน้าดาวน์โหลด |
| แอปมีปัญหา | ส่งไฟล์ log ที่ `%APPDATA%\NexusTube\logs\` มาให้ดูได้ |

## 6. ตั้งจากซอร์สโค้ด

```bash
git clone https://github.com/masuzu2/NexusTube.git
cd NexusTube
npm install
npm start      # dev
npm run dist   # build installer
```
ต้องมี Node.js 18+

## ค้นหาข้ามแพลตฟอร์ม & ตั้งค่า (3.10.0)

- ช่องค้นหาค้นได้ทั้ง YouTube และ Apple Music ในครั้งเดียว (badge ▶/♪ บอกแหล่งที่มา)
- เว็บโหลด (127.0.0.1:8787) มีแถบ ⚙️ ตั้งค่า: ฝังปก/metadata/เนื้อเพลง, SponsorBlock, normalize, และจำนวนโหลดพร้อมกัน 1–6
- เว็บโหลดรองรับสองภาษา (ไทย/EN) — เปลี่ยนได้ที่มุมบนซ้าย
- เมนู tray มีปุ่ม 🌐 เปิดเว็บโหลด และ 🐞 รายงานปัญหา (แนบ log ให้อัตโนมัติ)
